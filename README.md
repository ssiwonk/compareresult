# 🌐 슬라이드 비교 허브 & 다중 프로젝트 뷰어 (Slide Comparison Hub)

여러 주차(1주차, 2주차, ...) 또는 여러 프로젝트의 PPTX/PDF 슬라이드 비교를 **하나의 통합 웹 대시보드 허브**에서 관리하고 탐색할 수 있는 인터랙티브 웹 시스템입니다.

---

## 📁 새로운 다중 프로젝트 폴더 구조

앞으로 새로운 비교 대상이 생기면 `input/` 아래에 **폴더 하나만 새로 만들고 파일들을 넣으면 끝**납니다!

```
ppt-compare/
├── input/
│   ├── 1주차_음악치료프로젝트/      <-- [1주차 프로젝트]
│   │   ├── 1_원고_v1.pdf          (1번 기준 파일)
│   │   ├── 2_강의안_v2.pptx        (2번 비교 파일)
│   │   └── 3_스토리보드.pptx       (3번 비교 파일)
│   │
│   ├── 2주차_임상실습/             <-- [2주차 프로젝트 추가 시]
│   │   ├── 1_2주차_원고.pdf
│   │   └── 2_2주차_강의안.pptx
│   │
│   └── 3주차_사례연구/             <-- [3주차 프로젝트 추가 시]
│       ├── 1_3주차_원고.pptx
│       └── 2_3주차_발표자료.pdf
│
└── output/                        <-- [웹 배포용 통합 결과물]
    ├── index.html                 <-- ★ 메인 허브 대시보드 (모든 프로젝트 카드 목록)
    ├── projects.json / projects.js
    └── projects/
        ├── 1주차_음악치료프로젝트/
        │   ├── index.html         <-- 1주차 3단 비교 뷰어
        │   └── images/
        └── 2주차_임상실습/
            ├── index.html         <-- 2주차 비교 뷰어
            └── images/
```

---

## 🚀 사용 및 업데이트 방법

### 1. 새 프로젝트 추가 및 빌드
1. `input/` 폴더 안에 새 주차/프로젝트 폴더(예: `input/2주차/`)를 만들고 파일들을 넣습니다.
2. 터미널에서 빌드 명령어를 실행합니다:
   ```bash
   python build.py
   ```
3. 브라우저가 열리며 **메인 대시보드에 새 프로젝트 카드가 자동으로 추가**된 것을 확인할 수 있습니다.

### 2. GitHub에 변경 사항 반영 (웹 사이트 자동 갱신)
새 프로젝트를 추가한 뒤 아래 3줄만 실행하면 GitHub Pages에 실시간 반영됩니다:
```bash
git add .
git commit -m "add: 2주차 슬라이드 비교 추가"
git push
```

## 🌟 주요 기능 요약
- **통합 대시보드 허브**: 모든 주차/프로젝트의 슬라이드 썸네일, 파일 목록, 슬라이드 수를 카드 형태로 한눈에 검색 및 탐색
- **100% 원본 충실도 고화질 렌더링**: MS PowerPoint COM & PyMuPDF로 폰트/표 왜곡 없이 렌더링
- **1:N 분할 슬라이드 지능형 매핑**: 1번 슬라이드 1장에 대해 2, 3번 파일에서 2~3장으로 나뉜 구조를 자동 추적하여 한 행에 나란히 배치
- **라이트박스 줌 & 패닝**: 슬라이드 클릭 시 마우스 휠 확대/축소(`50% ~ 400%`) 및 드래그 이동 지원
- **홈으로 돌아가기(Hub Navigation)**: 각 주차별 뷰어 상단에서 `[허브 홈]` 버튼을 누르면 언제든 메인 대시보드로 복귀
